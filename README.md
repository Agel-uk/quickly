# Quickly MVP

Free bilingual MVP (English/Arabic) with 8 working tools:
- Percentage Calculator
- Bill Splitter
- Age Calculator
- Password Generator
- BMI Calculator
- Discount Calculator
- Word & Character Counter
- Tip Calculator

Features:
- Mobile-friendly responsive layout
- Search
- Arabic/English switching
- PWA manifest + service worker
- No registration required
- No paid services required

How to run:
1. Open index.html locally, or
2. Upload the folder to GitHub Pages / Cloudflare Pages / Netlify free tier.
